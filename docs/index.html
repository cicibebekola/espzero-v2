Built for the present

Modern firmware, practical hardware.

The project moves beyond a legacy stack with the official Espressif display and LVGL integration layers. Each building block is intentionally separated so future apps can share dependable device services.

01 / DISPLAY

LVGL 9 interface

A responsive 240 × 320 RGB565 interface driven through esp_lcd and Espressif’s LVGL port.

02 / INPUT

Shared SPI touch

The XPT2046 touch controller shares the display bus cleanly, with a dedicated interrupt line for efficient sleep handling.

03 / SERVICES

Ready for real apps

SD storage, battery monitoring, OTA partitions, and reusable device components underpin the app layer.

Target board

Designed around a familiar 3.2-inch ESP32 display module.

The pinout and buses are documented in the project context, including separate SPI channels for the display/touch pair and SD storage.
